# 💫 About Me:
Hello, my name is Zaed Hussain, and I am an AI/ML Engineer with a B.S. in Applied Mathematics from the University of Illinois Chicago and a Data Engineering Certificate from the University of Chicago with a focus in Insurance.

I specialize in designing, building, evaluating, and deploying AI applications and machine learning models. My expertise spans neural networks, deep learning, Transformer architectures, Large Language Models (LLMs), Generative AI, and agentic AI. I apply mathematical, statistical, and computational principles to develop intelligent models and production-ready AI systems that solve complex, real-world problems.

My machine learning interests focus on the architectures and techniques underlying modern AI, including neural network development, deep learning, representation learning, attention mechanisms, Transformer architectures, and foundation models. My work and technical interests include model development, training, fine-tuning, performance evaluation, hyperparameter optimization, inference optimization, and parameter-efficient fine-tuning techniques such as LoRA and QLoRA.

My generative and agentic AI work focuses on building LLM-powered applications, autonomous agents, and multi-agent systems. My technical interests include LLM integration, reasoning, structured outputs, tool calling, API integrations, workflow orchestration, Retrieval-Augmented Generation (RAG), embeddings, vector databases, semantic and hybrid search, retrieval optimization, and agent-to-agent communication.

Drawing on my background in applied mathematics and data engineering, I approach AI/ML engineering across the development lifecycle, from neural network architectures and deep learning to foundation models, Generative AI applications, retrieval systems, agent architecture, model evaluation, optimization, and production deployment.
